# Fantastic bed bug landing page

Static landing page with a six-step inspection request form.

## Hosting
Import this repository into Vercel, choose Other as the framework, leave the build command unset and use the repository root as the output directory. The entry page is index.html.

## Form integration
The form is a preview until QUOTE_ENDPOINT in index.html is connected to a submission service. It does not send or store enquiries while that value is empty.
